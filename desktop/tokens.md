# askin 디자인 토큰

## 색

**값의 실물은 `desktop/askin-desktop-prototype.html` 의 `#askin-desktop-v1` 블록에 있다.**
여기 표는 뜻과 근거를 적는다. 값을 바꿀 때는 프로토타입을 고치고 이 표를 맞춘다.
`desktop/canvas/gen.py` 는 그 파일에서 CSS 를 읽어 쓰므로 목업은 따로 고치지 않는다.

**면과 글자는 중립이다. 보라는 브랜드가 쓰는 자리에만 둔다.** 버튼, 선택 상태, 워드마크,
그래프 노드, 구체. 배경과 패널과 글자에는 보랏빛을 섞지 않는다. 사용자가 정했다.

| 토큰 | Light | Dark | 용도 |
|---|---:|---:|---|
| `--ask-bg` | `#FFFFFF` | `#0E0E10` | 앱 배경과 사이드바 |
| `--ask-panel` | `#FFFFFF` | `#17171A` | 메인·채팅 패널 |
| `--ask-panel-raised` | `#FFFFFF` | `#1D1D21` | 메뉴와 분석 설정 |
| `--ask-ink` | `#17171A` | `#F2F2F3` | 기본 글자 |
| `--ask-dim` | `#5B5B60` | `#B0B0B6` | 설명과 근거 |
| `--ask-faint` | `#727278` | `#8B8B91` | 시각과 보조 라벨 |
| `--ask-line` | `#E3E3E6` | `#2B2B2F` | 패널 테두리 |
| `--ask-line-soft` | `#EFEFF1` | `#202024` | 패널 내부 구분선, 그래프 면 |
| `--ask-purple` | `#7C3AED` | `#A78BFA` | 브랜드, 주 행동, 포커스 |
| `--ask-purple-hover` | `#5B21B6` | `#C4B5FD` | 호버 |

| `--ask-purple-soft` | `#F0E9FF` | `#2A2040` | 선택 탭, 사용자 말풍선, 추천 문장 |
| `--ask-purple-ink` | `#5B21B6` | `#C4B5FD` | 약한 보라색 면 위 글자 |
| `--ask-positive` | `#2E9463` | `#7DD3A7` | 완료 보조색 |
| `--ask-danger` | `#B4232F` | `#FF9AA5` | 오류 문구 |

Light 는 흰 패널 위에서 보조 글자 6.75:1, 약한 글자 4.78:1, 주 버튼 5.70:1 이다.
Dark 는 패널 위에서 보조 글자 8.29:1, 약한 글자 5.28:1, 주 버튼 6.35:1 이다.
중립으로 옮기면서 다시 쟀다. 약한 글자가 처음엔 4.39:1 로 4.5 에 못 미쳐 `#727278` 로 어둡게 했다.
주 버튼(`--ask-purple`)은 그래프 에이전트 노드 대비를 맞추며 `#6D28D9`→`#7C3AED` 로 밝혔다
(7.10:1→5.70:1). 여전히 4.5:1 을 넉넉히 넘는다.

**배경과 패널이 Light 에서 둘 다 순백이다.** 면을 가르는 것은 색이 아니라
`--ask-line` 테두리와 그림자다. 배경에 회색을 깔아 층을 만들지 않는다.

## 구체 전용 색

구체의 색은 UI 상태 토큰이 아니다. 셰이더와 룩 개발 안에서만 쓴다.

| 토큰 | 값 | 역할 |
|---|---:|---|
| `--orb-core` | `#7C3AED` | 보라색 중심 |
| `--orb-violet` | `#A78BFA` | 표면과 프레넬 빛 |
| `--orb-magenta` | `#E879F9` | 내부 흐름 1 |
| `--orb-blue` | `#60A5FA` | 내부 흐름 2 |
| `--orb-cyan` | `#22D3EE` | 내부 흐름 3 |
| `--orb-amber` | `#F59E0B` | 작은 온기, 전체 면적의 8% 이하 |
| `--orb-eye` | `#21172E` | Light 눈 |
| `--orb-eye-dark` | `#17121F` | Dark 눈 |

눈 레이어의 기본 위치는 구체 중심에서 `translateX(2px)`이다. 대기 상태 눈동자는 각 흰자의 기존 중심보다
오른쪽으로 `1px` 이동한다. 상태 애니메이션은 이 위치를 기준으로 더해지고, 상태가 끝나면 같은 위치로
돌아온다.

## 하네스 그래프 색과 밀도

| 토큰 | Light | Dark | 역할 |
|---|---:|---:|---|
| `--graph-project` | `#7C3AED` | `#A78BFA` | 현재 프로젝트 중심점 |
| `--graph-agent` | `#7C3AED` | `#A78BFA` | 메인·서브에이전트 |
| `--graph-skill` | `#2E9463` | `#7DD3A7` | 프로젝트·전역 스킬 |
| `--graph-mcp` | `#3B8EF0` | `#93C5FD` | MCP와 외부 도구 연결 |

흰 배경(`#FFFFFF`) 대비 기준: 노드는 면이라 3:1 이면 된다(WCAG 비텍스트 대비). 에이전트·프로젝트
5.70:1, 스킬 3.80:1, MCP 3.33:1 이다. MCP 는 기존 값(`#60A5FA`)이 2.54:1 로 3:1 에 못 미쳐서 바꿨다.
다크(`#0E0E10`) 대비는 세 값 다 바꾸기 전부터 3:1 을 넉넉히 넘었다(에이전트 7.09:1, 스킬 10.79:1,
MCP 10.69:1). 그래서 다크는 그대로 뒀다.

`--graph-agent`/`--graph-project` 는 `--ask-purple` 을, `--graph-skill` 은 `--ask-positive` 를,
`--graph-mcp` 는 `--ask-orb-blue` 를 그대로 쓴다. 별도 CSS 변수가 아니다. 이 값들은 그래프
바깥에서도 쓰인다. `--ask-purple` 은 버튼·포커스링·범례 글자에, `--ask-positive`/`--ask-orb-blue`
는 범례의 "스킬"/"MCP" 11px 글자색에도 쓰인다. 범례 글자는 텍스트라 4.5:1 이 기준인데, 스킬은
이번에 5.67:1 에서 3.80:1 로 내려가 4.5 밑으로 떨어졌다. MCP 는 원래도 2.54:1 로 4.5 미만이었고
지금은 3.33:1 로 나아졌지만 여전히 미달이다. 노드 자체는 기준(3:1)을 지킨다. 범례 글자까지
4.5:1 을 지키려면 그래프 전용 변수를 따로 둬야 한다.

노드는 14px 원형 점을 기본으로 하고 프로젝트 중심점은 20px다. 실제 클릭·키보드 포커스 영역은 최소
44px를 유지한다. 라벨은 점 아래 5px 간격으로 두며, 줌 단계는 `78% / 100% / 118%`의 목업 값을 쓴다.
실제 Sigma.js 구현에서는 화면 비율이 아니라 렌더링된 노드 크기에 따라 라벨 임계값을 연속적으로
계산한다. 멀리 보기에서는 프로젝트와 선택 노드만, 가까이 보기에서는 모든 이름을 보여준다.

## 레이아웃

값은 `desktop/askin-desktop-prototype.html`의 `.ask-layout` 등 실제 규칙과 대조했다. 어긋난 값은
프로토타입에 맞춰 고쳤고, 프로토타입에 해당 선언이 없는 값은 "토큰으로 안 들어감"이라고 적었다.

| 토큰 | 값 | 용도 |
|---|---:|---|
| `--shell-gap` | `8px` | 패널 사이 |
| `--shell-pad` | `8px` | 창 바깥 여백 |
| `--sidebar-w` | `200px` (창 920px 이상: `220px`), 앱에선 드래그로 `160~360px` | 프로젝트 사이드바 |
| `--chat-w` | `238px` (창 920px 이상: `300px`), 앱에선 드래그로 `220~420px` | 채팅 패널 |
| `--session-h` | 프로토타입에 아직 토큰으로 안 들어감 | 펼친 현재 세션 |
| `--panel-radius` | `14px` | 메인·채팅 패널 |
| `--control-radius` | `8px` | 버튼과 입력 |
| `--chip-radius` | `999px` | 추천 문장만 |
| `--control-h` | `40px` | 데스크톱 컨트롤 최소 높이 |
| `--row-h` | `40px` | 프로젝트와 탭 행 (`.ask-project`·`.ask-chat-tab`, `--control-h`와 같은 값) |

패널은 배경 위에 그림자로 띄우고, 패널 내부의 반복 항목은 그림자를 쓰지 않는다. 같은 radius를 중첩하지
않는다. 패널 안 14px 면에 8px 간격을 두고 중첩하는 입력은 8px로 둔다.

**앱에서는 사이드바·채팅 폭을 드래그로 바꿀 수 있다.** 프로토타입은 정적 데모라 이 표의 기본값을
그대로 쓰지만, `desktop/app/index.html`/`renderer.mjs` 는 위 표의 폭 사이 어디든 사용자가 고른
값을 CSS 변수(`--ask-sidebar-w`/`--ask-chat-w`)로 얹는다. 드래그하지 않으면 이 표의 기본값이 그대로
쓰인다. 최소·최대 근거:

- 사이드바 `160~360px`: 최소는 기본값(200~220px)의 약 4분의 3. 브랜드 마크와 "문서" 배지가 겹치지
  않는 선으로 잡았다. 최대는 사이드바가 메인 그래프 폭을 눈에 띄게 잠식하지 않는 선
- 채팅 `220~420px`: 최소는 입력창(전송 버튼 40px 포함)이 다음 줄로 안 깨지는 폭. 최대는 채팅 패널이
  메인 그래프보다 넓어지지 않는 선
- 메인(그래프) 패널의 최소 폭은 `320px`(`.ask-layout` grid-template-columns 의 `minmax(320px, ...)`).
  줌 컨트롤(약 116px)과 노드 팝오버(280px)가 겹치지 않는 선으로 잡았다

핸들은 패널 사이 `--shell-gap`(8px) 칸을 그대로 차지해 폭이 늘어나 보이지 않는다. 고른 폭은
`localStorage`(`askin.sidebarWidth`/`askin.chatWidth`)에 저장돼 앱을 다시 열어도 유지된다.

## 그림자와 모션

| 토큰 | Light | Dark | 용도 |
|---|---|---|---|
| `--ask-shadow` | `0 10px 28px rgb(0 0 0 / 6%)` | `0 16px 38px rgb(0 0 0 / 24%)` | 메인·채팅 패널, 모델 선택 |

그림자도 중립이다. 보랏빛 그림자(`rgb(31 27 45 / …)`)를 걷었다.

**한 겹인 이유가 있다.** `light-dark()` 안의 콤마는 인자 구분이라 `box-shadow` 레이어를
여럿 넣을 수 없다. 두 겹이 필요하면 `light-dark()` 를 쓰지 않고 미디어쿼리로 가른다.

| 모션 토큰 | 값 | 용도 |
|---|---:|---|
| `--motion-fast` | `120ms` | 호버와 누름 |
| `--motion-base` | `180ms` | 탭·접기·내용 교체 |
| `--motion-state` | `300ms` | 구체 상태 전환 |
| `--ease-out` | `cubic-bezier(.2, 0, 0, 1)` | 진입과 상태 변화 |
| `--ease-in` | `cubic-bezier(.4, 0, 1, 1)` | 퇴장 |

## CSS 는 어디에 있나

`gen.py` 에 CSS 를 붙여넣지 않는다. `desktop/canvas/gen.py` 의 `extract_proto_css()` 가
`desktop/askin-desktop-prototype.html` 에서 `#askin-desktop-v1` 블록을 읽어 그대로 쓴다.
프로토타입이 바뀌면 다음 실행에서 목업 열둘이 따라간다.

값을 두 곳에 적으면 어긋난다. 이 문서에 있던 CSS 사본은 그래서 걷었다.

## 상태 조합

| 상태 | 표현 | 글자 | 행동 |
|---|---|---|---|
| 빈 레포트 | 여백과 짧은 안내 | `분석하기를 눌러 하네스를 점검해봐요` | `분석하기` |
| 분석 설정 | 흰 설정 면, 필드 3개 이하 | 기간과 범위를 묻는다 | `분석 시작` |
| 분석 중 | 고정 높이 진행 상태 | 현재 읽는 범위 | 중복 실행 방지 |
| 레포트 있음 | 취약점 문장 2~4개 | 근거와 만들 하네스 | `채팅에서 고치기` |
| 판정 불가 | 일반 본문 대비 유지 | 이유를 단위 이름으로 설명 | 상세에서만 노출 |
| 채팅 비어 있음 | 구체와 추천 문장 3개 | 분석 전·후 문맥에 맞춤 | 추천 문장 선택 |
| 생성 중 | 구체 눈과 상태 문구 | `생각 중`, `작업 중`, `답변 중` | 입력은 계속 가능 |

모든 아이콘은 한 SVG 세트의 1.5px stroke와 `currentColor`를 쓴다. 아이콘 버튼은 최소 40×40px다.
버튼 누름은 `scale(.96)`이며 `transition: all`을 쓰지 않는다.
